PROJECT 2 DESIGN - STEP 1

IMPLEMENTED FOUNDATION
Facility is a record with ID, name, building, and category strings. Display
spelling remains separate from normalized comparison keys. ID normalization
trims outer whitespace and uppercases ASCII letters before format validation.
Valid IDs contain F followed by exactly three digits, including F000.

TextUtils provides consistent rules for all future loaders and name searches.
Trimming handles whitespace including tabs and carriage returns. Internal
spaces are preserved and significant. Pipe splitting retains empty fields,
including trailing fields, so loaders can detect malformed records. Only a
first non-whitespace # marks a comment; Room #5 remains ordinary data.

main.cpp currently handles startup and the optional data-directory argument.
The default is data/ relative to the working directory. No absolute campus
data path or sample records are embedded in the application.

Campus graph (Member B)
The campus graph is an undirected, unweighted graph stored as an adjacency list: a vector of building names plus, for each building, a vector of neighbor indexes. I chose an adjacency list because a campus has few connections per building, so memory grows with buildings plus connections instead of buildings squared, and neighbors naturally stay in the order they were added, which the assignment requires and which BFS depends on. Each accepted connection is added to both buildings' lists and counted once. Duplicate and reversed connections, self-connections and unknown buildings are rejected while loading. Buildings are looked up by a case-insensitive, trimmed scan of the name list, and the graph keeps the spelling from buildings.txt.
BFS reachability and shortest path both use std::queue and a visited vector that is marked when a building is added to the queue. Shortest path records each building's predecessor and rebuilds the path backward, so the first-discovered neighbor order breaks ties. The connectivity report counts components by running BFS from every unvisited building. The class is CampusGraph (include/CampusGraph.h, src/CampusGraph.cpp).
